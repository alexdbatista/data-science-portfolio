## Featured Projects

### 1. 🧪 [ToxPred Explainable: ADMET Cheminformatics Pipeline](./featured/toxpred-explainable/)

I built ToxPred to tackle a classic problem in early-stage drug discovery: confidently filtering out non-viable candidates before investing in costly wet-lab synthesis.

This project packages a complete end-to-end cheminformatics workflow. It parses molecular SMILES into 2048-bit Morgan fingerprints using `RDKit`, then feeds them through pre-trained Random Forest architectures to predict aqueous solubility, clinical toxicity bounds, and BBB (Blood-Brain Barrier) permeability. It's fully wrapped in a production-ready Streamlit interface that actively validates candidates against Lipinski's Rule of Five.

* **Tech Stack:** Python, RDKit, scikit-learn, Streamlit, PyTest
* **Key Results:** Achieved an R² ≈ 0.87 for solubility mapping (Delaney ESOL) and 76% accuracy predicting clinical trial failures (ClinTox).

### 2. 🔬 [Metabolomics Biomarker Discovery via LC–MS](./featured/metabolomics-biomarker-discovery/)

When designing clinical diagnostics, it's essential to narrow down a massive feature space to a handful of biologically critical targets to reduce assay R&D costs. 

In this repository, I outline the process of finding candidate biomarkers from high-dimensional LC–MS metabolomics data. Rather than just relying on black-box accuracy, I benchmarked sparse linear models (Lasso) against tree-based ensembles and coupled them with SHAP. This ensures that the global and local explanations are biologically sound and comprehensible to medical stakeholders in the loop.

* **Tech Stack:** Python, Pandas, scikit-learn, SHAP, Jupyter
* **Key Output:** A reproducible, chemometric pipeline ensuring clear biomarker prioritization, validated by straightforward SHAP decision plots.

### 3. 🔬 [QCL Breast Cancer Diagnostics: Spatial Deep Learning](./featured/qcl-breast-cancer-diagnostics/)

Standard histopathology relies on heavy chemical staining like H&E. I authored an automated workflow to classify malignant stroma directly from label-free Mid-IR hyperspectral cubes—generated by a Daylight Solutions Spero® QCL microscope.

This project spotlights heavy data engineering: it includes an out-of-core streaming pipeline to handle multi-gigabyte `.mat` Zenodo files seamlessly. The spatial segmentation relies on Manifold learning (PCA + UMAP) alongside a PyTorch U-Net architecture, deliberately maintaining strict DSGVO/GDPR compliance throughout patient data ingestion.

* **Tech Stack:** Python, scikit-learn, PyTorch, SciPy, Docker
* **Key Results:** 96.5% pixel accuracy and 86.6% mean IoU on tissue classification, viewable natively via a continuous Dash application deployment.
* **Live App:** [HuggingFace Spaces Deployment](https://huggingface.co/spaces/alexdbatista/qcl-breast-cancer-diagnostics)
